# Kartik Shukla - Portfolio Website

A static portfolio built with HTML, CSS and vanilla JavaScript. No build tools or dependencies.

## Files
- `index.html` - page content
- `style.css` - styling
- `script.js` - mobile menu, copy-email, current year, resume check
- `README.md` - this guide

## 1. Organize the files
Keep all four files in one folder (for example `kartik-portfolio`). Later, put `resume.pdf` in the same folder.

## 2. Preview locally
Double-click `index.html` to open it in your browser. No server is needed.

## 3. Add your resume
1. Save your resume as exactly `resume.pdf`.
2. Put it in the same folder as `index.html`.
3. Upload it to your GitHub repository (see below). Once the site is published, the "Download resume (PDF)" button appears automatically and the "coming soon" note disappears.
Note: the button does not appear when you open the page from your computer as a file; it works on the published site or a local server.

## 4. Publish free with GitHub Pages
1. Create an account at github.com.
2. Click **New repository**, name it (for example `portfolio`), set it to **Public**, and create it.
3. Click **Add file > Upload files**, drag in `index.html`, `style.css`, `script.js`, `README.md` (and `resume.pdf` when ready), then **Commit changes**.
4. Open **Settings > Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select branch `main` and folder `/ (root)`, then **Save**.
5. Wait 1 to 3 minutes. The page shows your site address, usually `https://YOUR-USERNAME.github.io/portfolio/`.
6. Open that address and check that all sections, links and the copy-email button work. If you named the repository `YOUR-USERNAME.github.io`, the address is `https://YOUR-USERNAME.github.io/`.

## 5. Update later
Edit the files, then in the repository use **Add file > Upload files** (same file names replace the old ones) or edit a file with the pencil icon, and commit. The site refreshes within a few minutes.

## Custom domain (optional)
Publishing and owning a custom domain are separate. The free GitHub address is enough; a domain is optional and costs money.

## Adding project details
In `index.html`, each project card has a Technologies, Features and Links row. Replace "To be added" only with information that is true. If you add a real repository or demo, add a link such as `<a href="REAL_URL">Repository</a>` in that card.
